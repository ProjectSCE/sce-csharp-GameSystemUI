# ChatSystem 聊天系统

## 概述

ChatSystem 是一个功能完整的多人游戏聊天系统，支持多种消息类型、实时消息传递、玩家管理和消息屏蔽功能。

## 功能特性

### 消息类型
- **私聊消息** (`Private`): 玩家之间的一对一私密聊天
- **队伍消息** (`Team`): 同队伍内部聊天
- **全体消息** (`All`/`World`): 向所有在线玩家发送消息
- **系统消息** (`System`): 服务器发送的系统通知

### 核心功能
- 🔄 **实时消息传递**: 基于服务端回音机制，确保所有玩家看到相同的消息显示效果
- 🛡️ **消息频率限制**: 30秒内最多发送5条消息，单条消息最大长度80字符
- 🎨 **丰富的UI界面**: 包含聊天记录面板、玩家列表和输入界面
- 🚫 **玩家屏蔽功能**: 支持单独屏蔽玩家或屏蔽所有玩家
- 🎯 **敏感词过滤**: 服务端消息内容检查机制（可扩展）
- 👥 **关系系统**: 根据玩家关系（盟友/敌人/中立）显示不同颜色

## 快速开始

### 1. 注册聊天系统

在游戏启动时，聊天系统会自动注册：

```csharp
public class ChatSystem : IGameClass
{
    public static void OnRegisterGameClass()
    {
        // 自动注册客户端和服务端处理器
    }
}
```

### 2. 使用聊天功能

#### 发送消息

```csharp
// 发送全体消息
await ChatMessageClient.SendMessageAll("大家好！");

// 发送队伍消息
await ChatMessageClient.SendMessageTeam("队友们集合！");

// 发送私聊消息
var targetPlayer = Player.GetById(targetPlayerId);
await ChatMessageClient.SendMessagePrivate(targetPlayer, "私聊内容");
```

#### 接收消息

```csharp
// 监听消息接收事件
ChatMessageClient.OnChatMessageReceived += (sender, message) => {
    // 处理接收到的消息
    Console.WriteLine($"收到消息: {message.ToString()}");
};
```

### 3. 私聊命令格式

这是预期要修改的模式，预期应该是/{昵称}
在聊天输入框中使用以下格式发送私聊消息：
```
/Player{玩家ID} 消息内容
```

例如：
```
/Player123 你好，这是私聊消息
```

## UI 组件说明

### ChatWindow - 聊天窗口
- 主聊天界面，包含两个标签页：聊天记录和玩家列表
- 支持拖拽和窗口控制
- 右侧关闭按钮

### ChatInputPanel - 输入面板
- 频道切换功能（全体/队伍）
- 输入框支持占位符文本
- 实时文本变化监听

### ChatRecord - 聊天记录
- 滚动显示聊天消息
- 自动滚动到最新消息
- 支持富文本颜色显示

### PlayerList - 玩家列表
- 按关系分组显示（友方/敌方/中立）
- 每个玩家显示头像、昵称、队伍信息
- 单独屏蔽按钮
- 全体屏蔽选项

## 消息显示颜色

根据玩家关系和消息类型，消息会以不同颜色显示：

- **私聊消息**: 粉色 (`#FF50EE`)
- **队伍消息**: 绿色 (`#70E383`)
- **全体消息**:
  - 盟友: 绿色 (`#70E383`)
  - 敌人: 红色 (`#E74747`)
  - 中立: 灰色 (`#B3B5BC`)
- **系统消息**: 黄色 (`#FFF395`)

## 限制和防护

### 消息频率限制
- 30秒内最多发送5条消息
- 超出限制时显示系统提示："发送消息过于频繁，请稍后再试"

### 消息长度限制
- 单条消息最大长度：80个字符
- 超出限制时会被阻止发送

### 敏感词过滤
- 服务端会对消息内容进行检查（`CensorMessage` 方法）
- 可根据需要扩展敏感词过滤逻辑

## 屏蔽功能

### 单独屏蔽
- 点击玩家列表中的屏蔽按钮可屏蔽特定玩家
- 被屏蔽的玩家消息不会显示在聊天记录中

### 全体屏蔽
- 开启后屏蔽所有玩家的消息
- 开启全体屏蔽时会自动清空单独屏蔽列表

## 技术实现

### 消息流程
1. 客户端发送消息到服务端
2. 服务端进行验证和过滤
3. 服务端将消息转发给目标接收者
4. 所有相关客户端（包括发送者）接收消息并显示

### 事件系统
使用 `TypedMessageHandler` 处理消息的注册和分发：
```csharp
TypedMessageHandler.Register<ChatMessage>(handler, MessagePriority.Normal, "HandlerName");
```

### UI数据绑定
使用GameData系统进行UI组件的数据绑定和模板化显示。

## 扩展开发

### 添加新消息类型
1. 在 `ChatMessageType` 枚举中添加新类型
2. 在客户端和服务端处理器中添加相应逻辑
3. 在UI显示中添加颜色和格式支持

### 自定义UI样式
修改各UI组件中的图片资源路径和颜色配置即可自定义外观。

### 消息持久化
可在服务端的 `SaveMessage` 方法中添加数据库存储逻辑。

## 性能优化建议

1. **消息历史管理**: 限制聊天记录的最大条数，避免内存占用过高
2. **频率控制**: 合理设置消息发送频率限制
3. **UI更新**: 使用事件驱动的UI更新机制，避免不必要的界面刷新
4. **网络优化**: 考虑消息批量发送和压缩

## 故障排除

### 常见问题
1. **消息不显示**: 检查消息处理器是否正确注册
2. **UI显示异常**: 确认所需的图片资源文件是否存在
3. **频率限制问题**: 检查系统时间和频率控制逻辑
4. **私聊格式错误**: 确保使用正确的 `/Player{ID}` 格式

### 调试信息
系统会输出详细的日志信息，可通过 `Game.Logger` 查看调试信息。
